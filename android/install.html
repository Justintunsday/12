Reading Assistant for Chrome & Edge

Install a bookmark that opens the assistant on your signed-in Fireflies assignment page. No browser extension is needed.

  1. Bookmark any ordinary webpage and name it Fireflies Assistant.
  2. Copy the complete code below. In your browser's Bookmarks menu, edit the bookmark and replace its URL with this code, including javascript:. Save.
  3. Sign in at Fireflies and open an individual assignment.
  4. Tap the address bar, type Fireflies Assistant, and tap the saved bookmark suggestion. If necessary, open it from the Bookmarks menu.
  5. Enter your own DeepSeek API key, tap 分析答案 (Analyze answers), review the explanations, then tap 一键勾选 (Select answers). Submit manually on the website.

If copying is unavailable, select all the text below and copy it manually.

Keep the assignment tab in the foreground during analysis. Keys and answers stay in that page's memory and are cleared when it reloads or closes.

The bookmark runs in the assignment page's context and calls the official DeepSeek API directly. Website policy or future browser changes may restrict it. Android device installation and the signed-in live workflow still need device verification.

If the browser removes javascript:, edit the saved bookmark and type that prefix back in. Pasting code into the address bar as a search does not install the bookmark.
